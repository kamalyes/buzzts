# buzzts
> 我计划在接下来的两周内，使用ChatGPT对该插件进行调整和优化，以解决其性能问题

这是一个简洁而功能强大的现代 TypeScript 工具库，使用该库可以有效提高你的开发效率，快速完成项目

# 特性

- ⚡️短小精悍，代码轻量
- ✅适用于现代ES6/2020规范
- 💫零依赖: 零Dependencies依赖，只会安装项目本身
- 📡可通过CDN引用: 同时支持jsdelivr和unpkg
- 🦾基于 TypeScript 开发，类型安全
- 🌎包含动态插件库，可以随时调用，做随手可得且最全的工具库
- ⚡️具备更多能力，等你去挖掘....

# 如何使用

## import

```bash
# npm
npm install buzzts

# yarn
yarn add buzzts

# pnpm 🔥
pnpm add buzzts
```

> 如果你不想在项目中引入太多依赖，而又想使用某一个方法
> 那么可以复制文档中的源码，在你的项目中引入

### CDN源

```bash
// CDN源：jsdelivr

https://cdn.jsdelivr.net/npm/buzzts@latest

CDN源：unpkg

https://unpkg.com/buzzts@latest
```
